# QuickClicker

Минималистичный автокликер для Windows с тестом скорости ручного клика.

Написан на C# / WinForms (.NET 9), без внешних зависимостей — только Win32 API
(низкоуровневые хуки клавиатуры/мыши и `SendInput`).

## Возможности

- **Автокликер** — жмёт выбранную кнопку мыши с заданным интервалом.
  - Кнопка клика: ЛКМ, ПКМ, СКМ, боковые X1/X2.
  - Интервал между кликами в миллисекундах (1 … 60000).
  - **Зажатие** — сколько миллисекунд кнопка реально удерживается нажатой
    между `down` и `up` (0 … 2000 мс). `0` — мгновенный клик.
    **Играм это критично:** при `0` нажатие и отпускание приходят в одном
    кадре, и игра, которая опрашивает *состояние* кнопки (так делает Unity,
    а значит и Valheim), просто не видит клик. Ставьте 10–30 мс.
  - **Метод клика**: `SendInput (обычный)` или `WM-сообщения (для игр)` —
    запасной способ доставки кликов в активное окно для «капризных» игр.
    Зажатие работает в обоих методах.
  - **Периодическая пауза** (опционально) — кликер может работать циклами:
    `Кликать (с)` секунд кликает, затем `Отдыхать (с)` секунд «отдыхает»
    и снова кликает. Выключено — работает непрерывно как раньше.
    Поля неактивны, пока галочка снята.
  - Точный тайминг (без накопления отставания), «Стоп» срабатывает мгновенно
    (зажатие и пауза прерываются, кнопка отпускается, ничего не «залипает»).
- **Кнопка вкл/выкл** — назначается по нажатию. Поддерживается **и клавиатура,
  и мышь**:
  - клавиши + модификаторы `Ctrl` / `Alt` / `Shift` (напр. `Ctrl + F6`);
  - **боковые кнопки мыши X1 / X2**, средняя кнопка (СКМ), а также ЛКМ/ПКМ.
  - Чтобы назначить: нажмите поле `Кнопка вкл/выкл:` и нажмите нужную клавишу
    или кнопку мыши.
  - **Переключатель всегда ровно один.** Назначили кнопку мыши — клавиша
    перестаёт работать (и наоборот). Раньше сохранённая клавиша продолжала
    срабатывать вместе с кнопкой мыши — это исправлено.
  - Работает глобально, даже когда окно кликера не в фокусе.
  - Опция `Блокировать кнопку` — не пропускает кнопку/клавишу в игру.
- **Тест ручного клика** — считает только **ваши** нажатия выбранной кнопки
  (клики самого кликера отсеиваются по флагу `LLMHF_INJECTED`) и показывает:
  количество кликов, последний / средний / минимальный интервал (мс) и клик/с —
  чтобы подобрать реальный интервал для кликера.
- Настройки сохраняются в `%APPDATA%\QuickClicker\settings.json`.

## Запуск

Двойной клик по `run.cmd` — он соберёт проект (при необходимости) и запустит
кликер **без чёрного окна cmd**: после старта окно консоли закрывается.

Если игра/Steam запущены от имени администратора — запускайте через
`run-as-admin.cmd` (иначе Windows (UIPI) блокирует отправку кликов в такое окно).

## Автономный .exe

```cmd
publish.cmd
```
Результат: `publish\QuickClicker.exe` — один файл, не требует установленного .NET.
Его запускают простым двойным кликом — консоль не появляется.

## Если кликер не работает в игре

1. **Поставьте «Зажатие» 10–30 мс.** Это главная причина: при `0` клик
   длится микросекунды и игра, опрашивающая состояние кнопки покадрово
   (Unity: `Input.GetMouseButton`) успевает его «не заметить».
2. **Включите кликер.** Назначьте переключатель на боковую кнопку мыши (X1/X2)
   и нажмите её — надпись рядом с кнопкой `Старт` сменится на «Работает».
   Если переключатель не срабатывает — он не был назначен, нажмите поле
   `Кнопка вкл/выкл:` и нажмите нужную кнопку мыши ещё раз.
3. **Игра должна быть в фокусе** (активным окном) — клики уходят в активное окно.
4. Попробуйте сменить `Метод клика` на `WM-сообщения (для игр)`.
5. Убедитесь, что **игра и кликер в одном режиме прав** (оба от админа или оба
   без) — используйте `run-as-admin.cmd`, если Steam запущен от админа.
6. В Valheim работает **оконный / безрамочный режим** надёжнее, чем
   полноэкранный exclusive.

Проверено на живом стенде (`holdcheck`): для `holdMs = 0` кнопка мыши
наблюдается нажатой **0,1 %** времени, для `10 мс` — **20 %**, для `30 мс` —
**34 %**, для `100 мс` — **64 %**. То есть при нулевом зажатии «нажатия» для
игры фактически не существует.

## Важно

Кликер эмулирует системные клики, поэтому некоторые игры с анти-читом могут
реагировать на такое вмешательство. Используйте на свой риск.
